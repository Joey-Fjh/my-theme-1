## Batch H7: stylesheet spacing ratchet

**Status:** executed; accepted by the user after review round 8 (2026-10-21) without a round 9 PASS (the user set the tier, AGENTS.md Review tiers).

**Why.** CSS readiness criterion 2 covers raw spacing in markup (`raw-spacing`) but not in `{% stylesheet %}` blocks; a rough count finds about 160 raw `padding`, `margin` and `gap` values in 32 Liquid files (gap found in 6-P1). Direction accepted (user, 2026-10-21): a ratchet like `stylesheet-font-size`, so no new raw value lands while the polish pass migrates the existing ones.

**Outcome.** `lint:theme` counts disallowed spacing declarations per file in `{% stylesheet %}` blocks against a baseline that may only fall.

**Design.**
- New rule `stylesheet-spacing` in `.agents/skills/check-theme-architecture/scripts/lib/stylesheet-ownership-lint.js`, beside `stylesheet-font-size`, same baseline file (`stylesheet-ownership-baseline.json`) and the same `--write-` / `--shrink-stylesheet-ownership-baseline` flags.
- Properties: `padding`, `margin`, `gap`, `row-gap`, `column-gap` and their side, inline and block longhands (`padding-top`, `margin-inline-start`, ...). Each declaration counts once.
- Allowed per value part (shorthands are split on top-level spaces): `0`, `auto`, `inherit`, `initial`, `unset`; a `var()` of a spacing or frame token (`--spacing-*`, `--page-*`); `%` and `em`; and `calc()` / `clamp()` / `min()` / `max()` built only from those plus unitless numbers. Anything else counts: `px`, `rem`, viewport units, other `var()`s.
- The baseline is written from the current counts once; entries only fall from here (polish pass).
- `docs/references/style-system/css-architecture.md`: the rule's paragraph and its row in the lint table.

**Implementation surface:** `.agents/skills/check-theme-architecture/scripts/lib/stylesheet-ownership-lint.js`, `.agents/skills/check-theme-architecture/scripts/theme-architecture.test.js`, `.agents/skills/check-theme-architecture/scripts/stylesheet-ownership-baseline.json`, `docs/references/style-system/css-architecture.md`, `package.json` and `package-lock.json` (the `@csstools/css-tokenizer` dev dependency and the `engines` floor only; added by the user's decision after review round 5), record files. Not in surface: any theme file.

**Acceptance checks.**
1. `git diff --name-only` plus untracked files: only surface files.
2. Tests: each allowed form passes (`0`, `auto`, `var(--spacing-step-m)`, `calc(var(--spacing-group) * 2)`, `clamp(var(--spacing-step-s), 2%, var(--spacing-step-l))`, `-var(...)` via `calc(-1 * var(--spacing-related))`, `0 auto`); each disallowed form counts (`12px`, `1.6rem`, `2vw`, `clamp(1rem, 2vw, 3rem)`, `var(--font-body-size)`, `0 1.6rem` counts once); comments and markup outside `{% stylesheet %}` are ignored; a count above the baseline fails, a drop is reported.
3. Baseline holds one `stylesheet-spacing` entry per file with hits; `npm.cmd run lint:theme` passes on the tree unchanged; adding one `padding: 12px` to a section stylesheet makes it fail (checked, then reverted).
4. `npm.cmd run test:theme-check`, `npm.cmd run lint:theme`, `npm.cmd run lint:doc-paths`, `npm.cmd run lint:records` pass; `git diff --check` clean.

**Review tier:** Ask (validator wiring). Verifier in a separate session; complete only on PASS.
